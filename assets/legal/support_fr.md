# Aide et contact

Une question sur l'application, votre accompagnement, un paiement ou une commande de livre ?

- Depuis l'application : onglet Messages, pour écrire directement à votre coach.
- Par e-mail : nathansallinone@gmail.com.

## Questions fréquentes

- Comment relier mon conjoint ? Profil → Mon accompagnement : partagez le code d'invitation ; votre conjoint le saisit dans « J'ai un code ».
- Comment payer un forfait ? Onglet Séances → Choisir : scannez le QR code avec votre application bancaire. Les séances sont ajoutées dès que le coach a reçu le virement.
- Comment rejoindre une séance ? Onglet Séances → Rejoindre sur Zoom, au moment du rendez-vous.
- Comment supprimer mon compte ? Profil → Supprimer mon compte.
