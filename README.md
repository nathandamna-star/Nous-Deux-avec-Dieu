# Nous deux avec Dieu

Application de coaching de couple chrétien (iOS et Android, Flutter + Firebase).
Le cahier des charges complet est dans [CLAUDE.md](CLAUDE.md).

## Lancer l'app sur un téléphone (Mac)

```
cd ~/nous-deux-avec-dieu
flutter pub get
flutter run
```

## Vérifier le code

```
flutter analyze
flutter test
```
